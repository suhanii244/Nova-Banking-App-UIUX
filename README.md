# Nova-Banking-App-UIUX
A modern mobile banking app UI/UX design created in Figma.

## Overview

Nova is a modern mobile banking application designed to provide users with a simple, secure, and seamless banking experience. The project was created in Figma with a focus on usability, clean design, and intuitive navigation.

## Features

- Modern and clean UI
- User-friendly navigation
- Account dashboard
- Money transfer flow
- Transaction history
- Payment confirmation screens
- Responsive mobile-first design

## Tools Used

- Figma
- Wireframing
- Prototyping

## Concepts Learned

- Responsive Mobile Layout
- Color Theory and Accessibility
- Wireframing and High-Fidelity Design
- Interactive Prototyping
